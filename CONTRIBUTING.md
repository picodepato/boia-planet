# Cómo colaborar

## Fuente de verdad

El alcance funcional se define en `BOIA_PLANET_Documento_Maestro_Definitivo_v14_TRES_PROMPTS.docx`. Si el prototipo y el documento difieren, prevalece el documento maestro. Las decisiones posteriores deben registrarse en una issue o pull request.

## Flujo de ramas

1. Crear una rama desde `main`: `feature/nombre-corto`, `fix/nombre-corto` o `docs/nombre-corto`.
2. Hacer commits pequeños y descriptivos.
3. Abrir una pull request con objetivo, capturas o vídeo, pruebas realizadas y riesgos conocidos.
4. Requerir al menos una revisión antes de integrar cambios relevantes.
5. No hacer `push --force` sobre `main`.

## Definición de terminado

- Cumple los criterios del documento maestro aplicables.
- Funciona en móvil y escritorio.
- Estados de carga, vacío, error y éxito están cubiertos.
- No rompe progreso anónimo ni sesiones registradas.
- Textos visibles están preparados para español e inglés.
- No contiene secretos, datos personales reales ni credenciales.
- Se han probado navegación por teclado, controles táctiles y rendimiento básico.
- Si añade contenido administrable, también añade su edición y validación en el panel de administración.

## Seguridad y administración

- Usar cuentas individuales; nunca compartir una contraseña de administrador.
- Activar doble factor para administradores.
- Exigir doble confirmación para eliminaciones y registrar acciones sensibles en auditoría.
- El saldo gastable y los puntos históricos de ranking son magnitudes separadas.
- Cualquier operación irreversible debe tener copia o recuperación cuando sea técnicamente viable.
